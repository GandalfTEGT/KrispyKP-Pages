Admission input is exactly `{mime,base64}`. PNG, JPEG and WebP still images must actually decode, match MIME/signature and container length/checksums, meet32–8192 dimensions,16million pixels and8MiB limits. Animation, SVG/GIF, truncation, spoofing, decoding/resource failures refuse. General aspect range1:8–8:1; Home1:4–4:1. Orientation is applied; alpha is retained for PNG/WebP. Fresh RGB/RGBA renditions omit EXIF/XMP/ICC/comments/PNG text and receive a second actual decode. Admission returns an asset record plus sanitized `renditionBase64` in a PRIVATE receipt. `importAsset` takes original bounded upload input and independently reproduces the same sanitized identity; do not replace it with the admission output bytes, since JPEG re-encoding can change content identity.

Asset fields are exactly `id,path,sha256,mime,width,height,bytes`. Identity is `asset.<lowercase sanitized SHA256>`; path is `assets/managed/images/<lowercase SHA256>.png|jpg|webp`. No imported filename/path. Asset SHA is uppercase64 hex. The8MiB asset and32MiB batch limits count original compressed image-file bytes AFTER base64 decoding, not base64 characters and not decoded raster memory. Up to10 imports/32MiB original encoded bytes per batch; catalog100 assets/128MiB sanitized bytes. CLI request JSON limit48MiB accommodates base64 overhead. Decoder runs fixed local Python/Pillow code with15second timeout; the1,141-file closure covers interpreter executables/DLLs/archives, standard-library source/bytecode/native modules and Pillow source/bytecode/native modules. Bytecode writes are disabled. Each cached result rechecks these dependency hashes. Operating-system, Node/npm/Chromium host installation trust is separate from this decoder closure; installed interpreter/Pillow dependency fingerprint must match `tools/media/decoder-policy.json`. Missing/changed runtime requires an explicit trusted dependency update; no installation/download is performed. `KKP_MEDIA_PYTHON` is trusted HOST configuration, never a request field.

Usage fields are exactly `assetId,alt,frame,fit,position,crop`. Required plain alt≤160. Frames: intrinsic/square/landscape16:9/portrait3:4. Fits:contain/cover. Position `{mode:center|focal,x,y}` has finite0–1 coordinates; center requires0.5/0.5. Crop is null or `{x,y,width,height}`, normalized inside the orientation-correct raster with at least32 decoded pixels per axis. Crop coordinates remain continuous fractions; no integer pixel crop is generated. Validate the unrounded fraction against the32-source-pixel minimum; generated CSS rounds percentages/ratio to8 decimal places. Intrinsic requires contain/center/null crop. Home requires intrinsic and preserves the actual theme widths150px above700,88px at421–700,104px at≤420. Managed page media node is exactly `{id,kind:image,media:true}`; usage target is `page.<slug>.<component-id>`. Original E1 `{id,kind:image,src,alt}` PNG nodes remain supported separately.

**Crop is visual framing, not redaction.** The full sanitized image remains available in public output, including pixels outside the visible frame. Derived CSS uses the bounded typed crop/fit/position; no arbitrary CSS/coordinates are accepted. Stable img identity/alt and nearest declared parent are retained. Private selection reports the visible frame, rather than the underlying enlarged cropped img.

Requests retain B/D/page fields and add `mediaOperations`, `mediaContractSha256`, `mediaStateSha256`, `usageInventorySha256`. Each operation is exactly `{id,kind,expectedOld,value}`:

- `importAsset`: id is the admitted sanitized asset id, expectedOld null, value original `{mime,base64}`. Existing catalog assets are reused without reimport. Unused NEW imports produce no public files/catalog records. Existing catalog/assets remain preserved; deletion is deferred.
- `setUsage`: id is the declared final Home/page target, expectedOld complete baseline usage or null, value complete final usage. New virtual imported assets resolve during the same mixed B/D/page/media plan without writing into baseline.
- `rebindShared`: id is original managed asset id, expectedOld `{assetSha256,usageInventorySha256,usages}` exactly copied from current shared proof, value `{assetId}`. It preserves each affected usage's alt/frame/fit/position/crop and refuses invalid replacement dimensions/crop. It never overwrites the old shared file.
